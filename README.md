# Maré Moda Praia · checkout (Beta)

Carrinho e checkout Quick sobre a VTEX (conta `quickdigitalpartnerbr`), gerada pelo painel da Quick a partir de
`checkout-vtex` v0.1.0. Leia `AGENTS.md` antes de começar.

```bash
corepack enable
yarn install
yarn dev
```

A compra termina no checkout nativo da VTEX. Nenhuma credencial da VTEX é necessária aqui.
